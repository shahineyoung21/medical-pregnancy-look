# medical-pregnancy-look

هذا مشروع بسيط لتطبيق متابعة الحمل يعمل كواجهة ويب مباشرة دون الحاجة إلى إعدادات معقدة.

## المميزات
- حساب الأسبوع الحالي للحمل
- حساب الشهر الحالي والمرحلة
- حساب الأيام المتبقية حتى تاريخ الاستحقاق
- حفظ البيانات محلياً في المتصفح
- قائمة مراجعة يومية

## التشغيل
1. افتح ملف `index.html` في المتصفح.
2. أدخل تاريخ الاستحقاق.
3. أضف الوزن، ضغط الدم، وملاحظاتك.

## الملفات
- `index.html` — الصفحة الرئيسية
- `style.css` — تنسيق الواجهة
- `script.js` — منطق الحسابات والحفظ

## ملاحظات
- هذا المشروع هو نسخة أولية قابلة للتطوير.
- يمكن توسيعه لاحقاً إلى تطبيق React أو Laravel أو Flutter حسب الحاجة.
